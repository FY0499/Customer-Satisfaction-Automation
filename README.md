# Customer Satisfaction NPS/CSAT Automation

An n8n automation concept for collecting customer satisfaction feedback, calculating NPS/CSAT metrics, and routing follow-up actions.

## Setup
1. Import the workflow JSON once added to this repository.
2. Configure survey/form input and a spreadsheet or database destination.
3. Set thresholds for follow-up and verify score calculations.
4. Test with synthetic responses before using real customer data.

## Security
Do not commit customer records, private spreadsheet IDs, or credentials. End-to-end testing is not confirmed.

## Project status
This README documents the project scope and setup expectations. The workflow export must be present in the repository before it can be imported; validate the finished workflow in your own n8n instance before relying on it.
